## 🚀 Projects

### 📊 Consumer Behavior Analysis — Data Analyst Project
> **EHTP · Python / Pandas / MySQL / Power BI · Mar 2026**

- Analyzed purchase records from 3,900 retail customers using Python and Pandas; wrote SQL queries in MySQL to pull revenue breakdowns, loyalty patterns, and seasonal demand.
- Built a Power BI dashboard to present results to non-technical reviewers. It had to be readable without me in the room — that constraint shaped every design choice.

🔗 [View Repository](https://github.com/HamzaIDM/customer-shopping-behavior-analysis)

---

### 🎮 Nine Men's Morris — AI Strategy Game Engine
> **EHTP · Advanced Algorithmics & Game Theory · C · Feb–Mar 2026**

- Built a complete game engine in C: placement, movement, mill detection, and capture phases, with ASCII board rendering for real time game visualization.
- Implemented Minimax with Alpha-Beta pruning and split the code into three independent modules — board representation, state machine, rule engine — so each part could be tested without touching the others.

🔗 [View Repository](https://github.com/HamzaIDM/JeuDeMoulin)

---

### 🐾 Automatic Animal Food Dispenser — Embedded Systems Simulation
> **EHTP · Classical Computing Project · Arduino / Wokwi · 2025**

- Autonomous IoT feeding system simulated on Wokwi using Arduino UNO.
- RTC DS1307 for time-based scheduling · 4×4 keypad input · I2C LCD 2004 display.
- Servo motor control (0°–180°) via state-machine firmware for precise portioning.

🔗 [View Simulation](https://wokwi.com/projects/449173652836253697)
